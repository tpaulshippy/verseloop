VerseLoop — Support

VerseLoop v1.0 for iPhone (iOS 17+) · ESV-only memorization with real spaced repetition.

Quick start

  1. Open Verses → +, type a reference (e.g. John 1:1 or Psalm 23:1-6), tap Fetch ESV text, then Save.
  2. Open Today, tap a due verse, and type the first letter of each word — then the book initial and numbers for the reference.
  3. Grade yourself: Again / Hard / Good / Easy. That grade drives the SM-2 schedule. Every grade has an 8-second Undo.

Backup, export, and moving devices

  • Encrypted backup: Settings → Synchronize Backup pushes an end-to-end encrypted snapshot. Auto-sync after changes is on by default.
  • Moving to a new phone: Settings → Prepare JSON export → Share, then Import JSON on the new device.

Delete My Data

There are no accounts — deleting your data is one tap and needs no email:

  1. In the app: Settings → Delete All My Data → Delete everything.
  2. This erases all verses, reviews, and history on the device, deletes the encrypted cloud backup for your sync code, and rotates the code.
  3. To stop future uploads without deleting: turn off Auto-sync after changes.

ESV & offline

The app ships with two public-domain KJV demo verses so it works offline. Real ESV text is fetched at runtime and cached on-device. ESV text © Crossway.
